## API Overview

**Base URL:** `https://localhost:5001/api` (Development)  
**Protocol:** HTTPS  
**Content-Type:** `application/json`  
**Authentication:** JWT Bearer Token  
**API Version:** v1

### Swagger/OpenAPI Documentation
Access interactive API documentation at: `https://localhost:5001/swagger`

## Authentication Endpoints

### 1. Login
**POST** `/api/auth/login`

Authenticate user and receive JWT access token and refresh token.

**Request Body:**
```json
{
  "username": "string",
  "password": "string"
}
```

**Response:** `200 OK`
```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refreshToken": "a1b2c3d4e5f6...",
  "role": "Doctor",
  "expiresIn": 900
}
```

**Errors:**
- `400 Bad Request` - Invalid input
- `401 Unauthorized` - Invalid credentials

---

### 2. Refresh Token
**POST** `/api/auth/refresh`

Get a new access token using refresh token.

**Request Body:**
```json
{
  "refreshToken": "a1b2c3d4e5f6..."
}
```

**Response:** `200 OK`
```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refreshToken": "g7h8i9j0k1l2...",
  "expiresIn": 900
}
```

---

### 3. Logout
**POST** `/api/auth/logout`

Invalidate refresh token and logout user.

**Headers:**
```
Authorization: Bearer 
```

**Response:** `204 No Content`

## Doctor Endpoints

### 1. Get All Doctors
**GET** `/api/doctors`

Retrieve list of all doctors.

**Headers:**
```
Authorization: Bearer 
```

**Query Parameters:**
- `specializationId` (optional): Filter by specialization
- `search` (optional): Search by name
- `pageNumber` (optional): Page number (default: 1)
- `pageSize` (optional): Items per page (default: 10)

**Response:** `200 OK`
```json
[
  {
    "id": 1,
    "name": "Dr. John Smith",
    "specializationId": 1,
    "specializationName": "Cardiology",
    "email": "john.smith@hospital.com",
    "phone": "555-0101",
    "licenseNumber": "MD12345"
  }
]
```

**Authorization:** Any authenticated user

---

### 2. Get Doctor by ID
**GET** `/api/doctors/{id}`

Retrieve specific doctor details.

**Headers:**
```
Authorization: Bearer 
```

**Response:** `200 OK`
```json
{
  "id": 1,
  "name": "Dr. John Smith",
  "specializationId": 1,
  "specializationName": "Cardiology",
  "email": "john.smith@hospital.com",
  "phone": "555-0101",
  "licenseNumber": "MD12345",
  "createdAt": "2026-01-15T10:30:00Z"
```

**Errors:**

### 3. Create Doctor
**POST** `/api/doctors`

Create a new doctor profile.

**Headers:**
```
Authorization: Bearer 
```

**Request Body:**
```json
{
  "name": "Dr. Sarah Johnson",
  "specializationId": 2,
  "email": "sarah.johnson@hospital.com",
  "phone": "555-0102",
  "licenseNumber": "MD12346"
}
```

**Response:** `201 Created`
```json
{
  "id": 2,
  "name": "Dr. Sarah Johnson",
  "specializationId": 2,
  "email": "sarah.johnson@hospital.com",
  "phone": "555-0102",
  "licenseNumber": "MD12346",
  "createdAt": "2026-02-04T14:20:00Z"

```

**Authorization:** Admin only

**Errors:**
- `400 Bad Request` - Validation errors
- `409 Conflict` - Email or license number already exists
- `403 Forbidden` - Insufficient permissions

### 5. Delete Doctor
**DELETE** `/api/doctors/{id}`

Soft delete a doctor (marks as deleted, preserves data).

**Headers:**
```
Authorization: Bearer 
```

**Response:** `204 No Content`

**Authorization:** Admin only

**Business Rule:** Cannot delete doctor with active patient assignments

**Errors:**
- `400 Bad Request` - Doctor has active patients
- `404 Not Found` - Doctor not found

### 3. Create Patient
**POST** `/api/patients`

Register a new patient.

**Headers:**
```
Authorization: Bearer 
```

**Request Body:**
```json
{
  "name": "Jane Wilson",
  "dateOfBirth": "1990-07-22",
  "gender": "Female",
  "email": "jane.wilson@example.com",
  "phone": "555-1002",
  "address": "456 Oak Ave, City, State 12345",
  "bloodGroup": "A+",
  "condition": "Diabetes"
}
```

**Validation Rules:**
- `name`: Required, max 200 characters
- `dateOfBirth`: Required, must be in the past
- `gender`: Required, must be 'Male', 'Female', or 'Other'
- `email`: Optional, must be valid email format, unique
- `phone`: Required, max 20 characters
- `bloodGroup`: Optional, valid blood group (A+, A-, B+, B-, O+, O-, AB+, AB-)

**Response:** `201 Created`
```json
{
  "id": 2,
  "name": "Jane Wilson",
  "dateOfBirth": "1990-07-22",
  "age": 36,
  "gender": "Female",
  "email": "jane.wilson@example.com",
  "phone": "555-1002",
  "bloodGroup": "A+",
  "condition": "Diabetes",
  "createdAt": "2026-02-04T16:00:00Z"
}
```

**Authorization:** Admin, Nurse

## Appointment Endpoints

### 1. Get Appointments
**GET** `/api/appointments`

Retrieve appointments based on filters.

**Headers:**
```
Authorization: Bearer 
```

**Query Parameters:**
- `doctorId` (optional): Filter by doctor
- `patientId` (optional): Filter by patient
- `from`: Start date (YYYY-MM-DD)
- `to`: End date (YYYY-MM-DD)
- `status` (optional): Filter by status (Scheduled, Completed, Cancelled)

**Response:** `200 OK`
```json
[
  {
    "id": 1,
    "doctorId": 1,
    "doctorName": "Dr. John Smith",
    "patientId": 1,
    "patientName": "John Doe",
    "startTime": "2026-02-05T10:00:00Z",
    "endTime": "2026-02-05T11:00:00Z",
    "status": "Scheduled",
    "notes": "Follow-up visit"
  }
]
```

**Authorization:** 
- Admin/Nurse: Can view all appointments
- Doctor: Can view own appointments
- Patient: Can view own appointments

### 3. Create Appointment
**POST** `/api/appointments`

Book a new appointment.

**Headers:**
```
Authorization: Bearer 
```

**Request Body:**
```json
{
  "doctorId": 1,
  "patientId": 1,
  "startTime": "2026-02-05T10:00:00Z",
  "notes": "Annual checkup"
}
```

**Validation:**
- `startTime` must be in the future
- Duration is automatically set to 1 hour
- No overlapping appointments for the same doctor

**Response:** `201 Created`
```json
{
  "id": 2,
  "doctorId": 1,
  "patientId": 1,
  "startTime": "2026-02-05T10:00:00Z",
  "endTime": "2026-02-05T11:00:00Z",
  "status": "Scheduled",
  "notes": "Annual checkup",
  "createdAt": "2026-02-04T17:00:00Z"
}
```

**Errors:**
- `409 Conflict` - Time slot already booked for this doctor

---

### 4. Update Appointment Status

## Error Responses

### Standard Error Format
```json
{
  "type": "https://tools.ietf.org/html/rfc7231#section-6.5.1",
  "title": "One or more validation errors occurred.",
  "status": 400,
  "errors": {
    "Email": ["The Email field is not a valid email address."],
    "Name": ["The Name field is required."]
  },
  "traceId": "00-abc123..."
}
```

### HTTP Status Codes

| Code | Meaning | Description |
|------|---------|-------------|
| 200 | OK | Request succeeded |
| 201 | Created | Resource created successfully |
| 204 | No Content | Request succeeded, no content to return |
| 400 | Bad Request | Invalid request data or validation error |
| 401 | Unauthorized | Missing or invalid authentication token |
| 403 | Forbidden | Insufficient permissions |
| 404 | Not Found | Resource not found |
| 409 | Conflict | Resource conflict (duplicate, time slot taken) |
| 500 | Internal Server Error | Server error |

### Common Error Examples

**401 Unauthorized:**
```json
{
  "type": "https://tools.ietf.org/html/rfc7235#section-3.1",
  "title": "Unauthorized",
  "status": 401,
  "detail": "Invalid or expired token"
}
```

**403 Forbidden:**
```json
{
  "type": "https://tools.ietf.org/html/rfc7231#section-6.5.3",
  "title": "Forbidden",
  "status": 403,
  "detail": "You do not have permission to perform this action"
}
```

**404 Not Found:**
```json
{
  "type": "https://tools.ietf.org/html/rfc7231#section-6.5.4",
  "title": "Not Found",
  "status": 404,
  "detail": "Doctor with id 999 not found"
}
```

**409 Conflict:**
```json
{
  "type": "https://tools.ietf.org/html/rfc7231#section-6.5.8",
  "title": "Conflict",
  "status": 409,
  "detail": "Appointment time slot is already booked"
}
```

## Rate Limiting

- **Rate Limit:** 100 requests per minute per IP
- **Headers:**
  - `X-RateLimit-Limit`: Maximum requests allowed
  - `X-RateLimit-Remaining`: Remaining requests
  - `X-RateLimit-Reset`: Time when limit resets
